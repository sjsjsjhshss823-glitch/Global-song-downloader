# Global Song Downloader

אפליקציית מוזיקה בעברית לטלפון.

## גרסת התחלה
- ממשק בעברית ובכיווניות RTL.
- חיפוש במקורות מוזיקה חוקיים.
- נגן שמע לקבצים מקומיים ולקישורי שמע ישירים.
- רשימת השמעה זמנית.

## מקורות
- Jamendo: https://www.jamendo.com/
- Internet Archive: https://archive.org/details/audio
- Audius: https://audius.co/
- Free Music Archive: https://freemusicarchive.org/

יש להוריד רק תוכן שהורדתו מותרת לפי רישיון היוצר ותנאי המקור. אין עקיפת DRM, מנויים או מגבלות גישה.

## מצב
זהו שלד ראשוני. בהמשך נוסיף ממשק עובד, PWA ואפליקציית Android מקורית.
