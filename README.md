# Global Songs

אפליקציית Web/PWA בעברית לחיפוש, ניגון וניהול מוזיקה ממקורות פתוחים.

## מה עובד בגרסה זו
- חיפוש ב־Internet Archive באמצעות Advanced Search API.
- סינון ראשוני לפריטים שמצהירים על רישיון Creative Commons / נחלת הכלל.
- איתור קובצי שמע זמינים בפריט והוספתם לספרייה.
- ניגון והורדת קבצים כאשר המקור מאפשר זאת.
- פתיחת קובצי שמע מהמכשיר.
- שמירת רשימת קישורים מקומית, התקנה כ־PWA ומטמון בסיסי.

## הפעלה
האתר צריך להיות מוגש דרך HTTPS (למשל GitHub Pages) כדי ש־Service Worker והתקנה יעבדו. פתחו את האתר ב־Chrome באנדרואיד ובחרו "התקנת אפליקציה" או "הוספה למסך הבית".

## מגבלות חשובות
- אין מכסת הורדות מלאכותית באפליקציה, אך אין אפשרות להבטיח שכל שיר בעולם זמין להורדה.
- החיפוש מסנן לפי הצהרת רישיון שמגיעה מהמקור; יש לבדוק את תנאי הפריט ואת זכויות השימוש לפני הורדה, הפצה או שימוש מסחרי.
- אין עקיפת DRM, מנויים, חומות תשלום, הגבלות גישה או תנאי שירות של פלטפורמות.
- חלק מהאתרים אינם מספקים API ציבורי או דורשים הרשאות/מפתחות; הם מוצגים כקישורים חיצוניים בלבד.
- קובצי משתמש מקומיים אינם מועלים לשרת.

## פריסה
הוגדר workflow לפריסת GitHub Pages דרך GitHub Actions. ייתכן שיהיה צורך לבחור Settings → Pages → Build and deployment → Source: GitHub Actions במאגר לפני שהפריסה הראשונה תצליח.
